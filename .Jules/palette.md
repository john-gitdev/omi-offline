## 2024-11-20 - Ensure All IconButtons Have Explicit Tooltips
**Learning:** Custom `IconButton`s, particularly those used in prominent navigational locations like `AppBar` `leading` fields, must always include an explicit `tooltip` property. Flutter does not automatically infer semantic labels for icon-only buttons unless they are standard Flutter icons (like `Icons.arrow_back` inside an `AppBar` where it might provide default semantics). Without an explicit tooltip, screen readers and hover states lack essential context, making these crucial interactive elements inaccessible to visually impaired users and confusing for mouse users.
**Action:** When adding or reviewing `IconButton`s in Flutter applications, especially those using custom icons (e.g., `FaIcon`), verify that a descriptive `tooltip` attribute is explicitly provided.
