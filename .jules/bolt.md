## 2026-05-13 - Zero-copy memory slicing in Dart
**Learning:** Dart's `Uint8List.sublist()` creates an expensive deep copy of the array, which severely degrades performance when processing large buffers like audio PCM frames in tight loops. Additionally, nesting `ByteData.sublistView(Uint8List.fromList(data.sublist(...)))` inside loops compounds this by allocating a new list and view per iteration. For string decoding, passing `.sublist()` to `String.fromCharCodes()` unnecessarily allocates intermediate arrays instead of directly consuming bytes.
**Action:** Always use the static constructor `Uint8List.sublistView(bytes, start, end)` for zero-copy slicing when you only need a view into the byte buffer. Hoist single `ByteData.sublistView()` wrappers outside of loops and access bytes via offsets. When converting chunks of bytes to strings, use the native positional arguments like `String.fromCharCodes(data, start, end)` to avoid creating deep copy arrays.
