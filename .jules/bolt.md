## 2025-04-11 - Asynchronous I/O to avoid UI blocking
**Learning:** Dart's File API provides both synchronous (e.g. `listSync()`, `lastModifiedSync()`) and asynchronous (e.g. `list()`, `lastModified()`) methods. In an app where lots of recordings or segments might be read continuously in a getter method (like `getBatches()` in `RecordingsManager`), using synchronous methods can severely block the UI thread, causing jank. Since `fromFile` uses `existsSync` and `readAsBytesSync` under the hood to get the duration metadata of a recording, iterating over lots of segments blocking the main thread can lead to UI hangs.
**Action:** Replace synchronous I/O operations (`listSync`, `lastModifiedSync`, `existsSync`, `readAsBytesSync`, `lengthSync`) with their async equivalents when running over directories mapping metadata into memory or building out lists to be passed along to UI components. Use `await` inside sequential `for` loops to safely retrieve records asynchronously without sacrificing insertion order if needed.
